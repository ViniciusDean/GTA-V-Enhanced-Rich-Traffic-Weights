# Security and usage

This mod is intended only for GTA V Enhanced Story Mode offline.

- Do not load the ASI plugin while entering GTA Online.
- Obtain Script Hook V only from its official website.
- Verify release files against `dist/SHA256SUMS.txt`.
- Back up the original `popgroups.ymt` before installation.

For reproducible bug reports, include the game build, zone code and relevant lines from `RichTrafficWeights.log`. Do not upload personal paths or unrelated game logs.
